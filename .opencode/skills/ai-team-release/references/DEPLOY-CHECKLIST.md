# Deploy Checklist

> 每次发布复制一份，逐项勾选并附证据路径。

## 版本

- [ ] 版本号/tag：
- [ ] commit：
- [ ] 镜像/制品 digest：
- [ ] 变更范围：
- [ ] 关联 TASK/FR：

## 质量门禁

- [ ] CI 全绿（链接）：
- [ ] 单元/集成/E2E：
- [ ] QA 报告（路径）：
- [ ] 代码审查通过（路径）：
- [ ] 安全审查通过（路径）：
- [ ] 无 P0/P1、Critical/High：

## 数据

- [ ] 迁移脚本已审查：
- [ ] 迁移在 staging 执行：
- [ ] 备份完成/可恢复：
- [ ] 回滚脚本：
- [ ] 数据兼容（expand/contract）：

## 配置/密钥

- [ ] 环境变量清单：
- [ ] Secret 来源（KMS/Secret Manager）：
- [ ] 证书/域名有效期：
- [ ] 第三方凭据/配额：
- [ ] 无密钥入库/入镜像/入日志：

## 基础设施

- [ ] 容量/副本/资源限制：
- [ ] DB/Redis/队列/存储健康：
- [ ] 网络/安全组/防火墙：
- [ ] DNS/CDN：
- [ ] 依赖服务版本兼容：

## 发布

- [ ] 生产批准（人/时间）：
- [ ] 变更窗口：
- [ ] 灰度/蓝绿策略：
- [ ] 回滚触发条件：
- [ ] 回滚负责人：
- [ ] 监控仪表盘：
- [ ] 告警静默/升级策略：

## 部署后

- [ ] 健康检查：
- [ ] 冒烟：
- [ ] 错误率/延迟：
- [ ] 日志异常：
- [ ] 业务指标：
- [ ] 用户反馈：
- [ ] 监控窗口结束：
- [ ] REL-* 记录：
- [ ] release notes：
- [ ] 复盘（如事故）：
