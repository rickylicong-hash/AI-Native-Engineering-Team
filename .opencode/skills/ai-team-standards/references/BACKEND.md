# BACKEND — 后端交付检查清单（1.15.0）

> 用法：`变更面` 为 `BE` 或 `full-stack` 的 brief 引用本文件；reviewer/security/QA 按清单验收。
> 本文件不是新角色，也不绑定框架；项目按自己的 Controller/路由/ORM/迁移栈落地。

## 1. 契约与端点

- [ ] 契约中声明的端点有 Controller/路由实现，或 `ENDPOINT-MAP.json` 明确 `deferred` + DEC/RISK；
- [ ] 方法/路径/状态码/错误码与契约逐字一致；
- [ ] 请求/响应 schema、分页、排序、幂等键有契约依据；
- [ ] 契约变更同一提交更新契约测试与版本说明；
- [ ] 不把“service 层有方法”当成“端点已交付”。

## 2. 事务与一致性

- [ ] 事务边界明确；失败全回滚，无部分提交；
- [ ] 幂等键作用域（租户/主体/路由）正确；
- [ ] 并发 CAS / 行锁 / 唯一约束有确定行为；
- [ ] 外部调用失败有超时、重试、补偿或明确失败；
- [ ] 资源（连接/会话/执行位/租约）在取消、超时、异常、重复释放路径都释放且幂等。

## 3. 数据与迁移

- [ ] 迁移可回滚/向后兼容；大表变更说明锁与耗时；
- [ ] 索引覆盖查询；无 N+1/无界查询；
- [ ] 租户隔离在存储/缓存/对象/向量/事件全链路；
- [ ] 删除/保留/导出策略与契约一致；
- [ ] 不创建契约未声明的“临时表”作为长期方案。

## 4. 安全

- [ ] 每个入口服务端鉴权；权限 AND/OR 与契约一致；
- [ ] 跨租户一律 404，同租户越权 403，不泄露存在性；
- [ ] 参数化查询、输出编码、SSRF/命令注入/反序列化防护；
- [ ] 密钥不落库/日志；凭据只写不读，指纹可核；
- [ ] 审计失败必须 fail-closed 或明确回滚；
- [ ] 错误体不泄露内部路径/堆栈/凭据。

## 5. 可观测性与测试

- [ ] 结构化日志含 trace/run/tenant（脱敏）；
- [ ] 关键路径有指标/告警；拒绝原因可区分；
- [ ] 单元 + 集成 + 契约测试；负向用例覆盖拒绝顺序；
- [ ] 定向测试 + 冻结候选全量基线（`baseline_id`）；
- [ ] 真实依赖 E2E 只对冻结候选执行。

## 6. 反模式

- 契约有端点、实现无 Controller，FR 仍标 done；
- 只测 happy path，不测回滚/部分失败/重复释放；
- 用“重跑通过”关闭 flaky 或 P1；
- 迁移只写 up，不写回滚；
- 审计 best-effort 导致“操作成功但无审计”。
