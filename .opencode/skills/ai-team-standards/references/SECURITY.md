# Security Reference — OWASP / STRIDE / 供应链

> 基线：OWASP ASVS L2（按风险可到 L3）、OWASP Top 10、CWE Top 25、STRIDE、NIST SSDF、SLSA、SBOM（SPDX/CycloneDX）。
> 本文是检查清单，不是法律/合规意见；强监管项目需专业审计。

## 1. 威胁建模（STRIDE）

对每个信任边界：

| 威胁 | 问题 | 控制 |
|---|---|---|
| Spoofing | 谁能冒充用户/服务？ | 强认证、MFA、mTLS、会话绑定、短期 token |
| Tampering | 请求/数据能否被改？ | 签名、HMAC、完整性校验、参数化、事务 |
| Repudiation | 操作能否否认？ | 审计日志、时间戳、不可篡改存储 |
| Information disclosure | 数据会泄露？ | 加密、最小权限、脱敏、错误信息收敛 |
| Denial of service | 能否被打垮？ | 限流、配额、超时、熔断、降级、WAF |
| Elevation of privilege | 能否越权？ | 服务端鉴权、租户隔离、最小权限、二次确认 |

输出：资产 → 信任边界 → 攻击路径 → 现有控制 → 缺口 → 风险等级 → 建议。

## 2. OWASP Top 10 检查

### A01 访问控制失效

- [ ] 每个入口服务端鉴权，不依赖前端隐藏；
- [ ] 对象级授权（IDOR）：用户只能访问自己的资源；
- [ ] 租户隔离：查询/缓存/队列/文件/搜索都带租户上下文；
- [ ] 默认拒绝；管理员操作二次确认/审计；
- [ ] 目录遍历/路径穿越防护；
- [ ] CORS 白名单，不用 `*` 带凭据；
- [ ] JWT：校验签名/算法/过期/受众；不信任 `alg: none`。

### A02 加密失效

- [ ] 传输 TLS 1.2+；HSTS；
- [ ] 静态加密（磁盘/字段/备份）；
- [ ] 密码哈希：Argon2id/bcrypt/scrypt + salt；不用 MD5/SHA1；
- [ ] 密钥管理：KMS/Secret Manager；轮换；不入库明文；
- [ ] 不把敏感数据放 URL/日志/缓存；
- [ ] 随机数用 CSPRNG。

### A03 注入

- [ ] SQL：参数化/ORM；不拼接；
- [ ] NoSQL：类型校验/操作符白名单；
- [ ] OS 命令：避免 shell；必须时参数化/白名单；
- [ ] LDAP/XPath/模板注入防护；
- [ ] 反序列化：不反序列化不可信数据；白名单类型；
- [ ] 日志注入：转义换行/控制字符。

### A04 不安全设计

- [ ] 威胁建模；
- [ ] 业务逻辑滥用（价格/数量/优惠券/竞态）；
- [ ] 限流/防枚举/防爆破；
- [ ] 失败安全（fail closed）；
- [ ] 资源消耗上限；
- [ ] 多步骤流程的幂等/顺序校验。

### A05 安全配置错误

- [ ] 默认账户/密码移除；
- [ ] 错误页不泄露堆栈/版本/路径；
- [ ] 安全 Headers：CSP、X-Content-Type-Options、Frame-Options、Referrer-Policy；
- [ ] 关闭调试/管理端点或加保护；
- [ ] 云存储/IaC 最小权限；无公开 bucket；
- [ ] 容器非 root/只读 FS/最小镜像。

### A06 易受攻击/过时组件

- [ ] lockfile 提交；版本 pin；
- [ ] CVE 扫描（npm/pip/cargo/go/osv/trivy）；
- [ ] 许可证清单；
- [ ] SBOM；
- [ ] 镜像 digest；基础镜像更新策略；
- [ ] 不引入无人维护的依赖。

### A07 认证/会话失效

- [ ] 登录限流/防爆破；
- [ ] 会话过期/注销/撤销；
- [ ] Cookie：Secure/HttpOnly/SameSite；
- [ ] MFA（高风险）；
- [ ] 密码重置 token 一次性/短时；
- [ ] 防会话固定/CSRF。

### A08 软件/数据完整性失效

- [ ] CI/CD 权限最小化；保护主分支；
- [ ] 制品签名/校验；
- [ ] 依赖来源可信；
- [ ] 更新签名/回滚保护；
- [ ] 不执行未验证的脚本/模型/插件。

### A09 日志/监控失效

- [ ] 认证/授权/管理操作/数据导出审计；
- [ ] 日志脱敏；不记录密码/token/密钥/PII；
- [ ] 告警可执行；有 runbook；
- [ ] 日志完整性/保留；
- [ ] 异常检测/速率限制。

### A10 SSRF

- [ ] 不直接请求用户提供的 URL；
- [ ] 允许列表/域名解析后校验；
- [ ] 禁止访问内网/元数据（169.254.169.254）/localhost；
- [ ] 重定向跟随限制；
- [ ] 出网默认拒绝。

## 3. LLM / AI 应用（OWASP LLM Top 10）

- [ ] Prompt injection：系统/用户内容隔离；工具调用白名单；不把网页/文件当指令；
- [ ] 不安全输出：渲染前转义；代码/命令不自动执行；
- [ ] 训练/检索数据泄露：租户隔离、最小权限、脱敏；
- [ ] 模型拒绝服务：限流、超时、token 上限、成本预算；
- [ ] 供应链：模型/权重/插件来源与校验；
- [ ] 过度代理：最小工具权限、高风险动作人工确认；
- [ ] 系统提示泄露：不把密钥/内部规则放 prompt；
- [ ] 幻觉/错误信息：引用/置信度/人工复核；
- [ ] 向量/嵌入：租户隔离、删除传播；
- [ ] 红队：越狱、数据外传、工具滥用。

## 4. 供应链 / SLSA

- [ ] 依赖来源（官方 registry/镜像）；
- [ ] lockfile + 校验和；
- [ ] CI 使用 OIDC/短期凭据，不用长期密钥；
- [ ] 构建可复现；制品签名（cosign/sigstore）；
- [ ] SBOM（CycloneDX/SPDX）；
- [ ] 镜像扫描 + digest pin；
- [ ] 分支保护/代码审查/双人批准（高风险）；
- [ ] 发布权限最小化；分离构建/发布。

## 5. 隐私 / 数据

- [ ] 数据分类（公开/内部/敏感/高敏感）；
- [ ] 最小化收集；目的限制；
- [ ] 保留期/删除/导出；
- [ ] 跨境/第三方处理；
- [ ] 脱敏/假名化；
- [ ] 同意/审计（按适用法规）；
- [ ] 备份加密/访问控制；
- [ ] 数据泄露响应流程。

## 6. 安全审查证据

每个结论附：

- 命令 + 退出码；
- 报告路径（SARIF/JSON/文本）；
- 误报判断；
- 攻击路径（不是只有 CVE 编号）；
- 关闭条件与 owner。

## 7. 发布放行规则

- Critical/High：阻断，必须修复或用户书面接受（记录风险与补偿控制）；
- Medium：修复计划/时间表，或书面接受；
- Low：backlog；
- 无证据的“安全”结论不算通过。
