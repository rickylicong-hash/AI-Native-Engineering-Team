# UX / Accessibility Reference

> 基线：WCAG 2.2 AA、Nielsen 10 heuristics、W3C Design Tokens、Atomic Design、平台 HIG/Material。

## 1. 核心原则

1. **任务优先**：用户来完成任务，不是来欣赏界面。
2. **可预测**：相同操作相同结果；位置/命名/交互一致。
3. **可恢复**：危险操作可撤销/确认；错误可修复。
4. **少记忆**：识别优于回忆；默认值合理；上下文保留。
5. **快反馈**：点击/提交/加载有即时状态；长任务可取消/后台。
6. **可访问**：不把任何人排除在外。
7. **克制**：不堆功能/动效/颜色；留白是设计。

## 2. Nielsen 10 Heuristics 检查

- [ ] 系统状态可见（loading/进度/成功/失败）；
- [ ] 系统与真实世界匹配（用户语言，不是实现术语）；
- [ ] 用户可控（撤销/重做/取消/退出）；
- [ ] 一致性与标准；
- [ ] 错误预防（约束/确认/默认安全）；
- [ ] 识别优于回忆（可见选项/上下文）；
- [ ] 灵活高效（快捷键/批量/高级选项）；
- [ ] 美观极简（每屏一个主任务）；
- [ ] 帮助用户识别/诊断/恢复错误；
- [ ] 帮助与文档（上下文帮助）。

## 3. 状态清单（每个页面/组件）

| 状态 | 要求 |
|---|---|
| Default | 正常内容/布局 |
| Hover/Focus | 可见反馈；焦点环不被移除 |
| Active/Pressed | 明确反馈 |
| Disabled | 说明原因/如何启用（tooltip/helper） |
| Loading | 骨架/进度；避免布局跳动；可取消（长任务） |
| Empty | 说明为什么空 + 下一步动作 |
| Error | 发生了什么 + 怎么修 + 重试；不泄露内部信息 |
| Partial | 部分成功/部分失败；可重试失败项 |
| Success | 明确结果 + 下一步 |
| No permission | 说明权限/申请方式；不假装 404 |
| Offline | 缓存/重试/同步状态（如适用） |

## 4. 可访问性（WCAG 2.2 AA）

### 可感知

- [ ] 非文本内容有 alt/角色；
- [ ] 视频有字幕/文字稿；
- [ ] 不只靠颜色/形状传达信息；
- [ ] 对比度：正文 ≥ 4.5:1；大字 ≥ 3:1；UI 组件 ≥ 3:1；
- [ ] 文本可放大 200% 不丢失内容；
- [ ] 重排：320px 宽可用。

### 可操作

- [ ] 键盘可达所有功能；
- [ ] 无键盘陷阱；
- [ ] 焦点顺序合理、焦点可见；
- [ ] 跳过导航/ landmarks；
- [ ] 触控目标 ≥ 24×24（推荐 44×44）；
- [ ] 不强制时限；可暂停/延长；
- [ ] 动效可关闭（`prefers-reduced-motion`）；
- [ ] 不依赖拖拽（提供替代）。

### 可理解

- [ ] 页面语言 `lang`；
- [ ] 标题层级正确；
- [ ] 表单标签/说明/错误关联；
- [ ] 错误建议可执行；
- [ ] 导航/命名一致；
- [ ] 不突然改变上下文。

### 健壮

- [ ] 语义化 HTML/ARIA 正确；
- [ ] 自定义组件有角色/状态/键盘；
- [ ] 屏幕阅读器关键路径可用；
- [ ] 兼容主流浏览器/辅助技术。

## 5. 设计系统

### Token 结构

```text
color:
  brand.500
  neutral.0/50/100/.../900
  semantic.success/warning/danger/info
  surface.default/raised/sunken
  text.primary/secondary/disabled
space: 0,1,2,3,4,6,8,12,16,24,32,48,64
radius: sm/md/lg/full
font:
  family.sans/mono
  size.xs/sm/md/lg/xl/2xl
  weight.regular/medium/semibold/bold
  lineHeight.tight/normal/relaxed
shadow: sm/md/lg
zIndex: base/dropdown/sticky/modal/toast/tooltip
motion: fast/normal/slow + easing
```

### 组件规格

每个组件写：

- 用途/何时用/何时不用；
- 结构/变体/尺寸；
- 状态（default/hover/focus/active/disabled/loading/error）；
- 间距/尺寸/token；
- 键盘/ARIA；
- 内容限制；
- 验收清单。

## 6. 响应式

| 断点 | 宽度 | 规则 |
|---|---|---|
| mobile | < 640 | 单列；底部导航；触控优先 |
| tablet | 640–1024 | 2 列/侧栏可折叠 |
| desktop | > 1024 | 多列；悬停增强但不依赖 |

检查：

- [ ] 320/375/768/1024/1440 宽度；
- [ ] 横屏/竖屏；
- [ ] 长文本/本地化/RTL；
- [ ] 软键盘不遮挡输入；
- [ ] 安全区（刘海/底部手势）。

## 7. 文案

- 按钮：动词 + 对象（“保存更改”，不是“确定”）；
- 错误：发生了什么 + 为什么 + 怎么修；
- 空态：为什么空 + 下一步；
- 确认：后果 + 不可逆提示；
- 不用技术术语/内部错误码作为主文案；
- 不用“请稍候”代替进度；
- 语气一致、简洁、尊重。

## 8. 交付检查

- [ ] 流程/状态/边界完整；
- [ ] token/组件可直接实现；
- [ ] 键盘/对比度/缩放检查；
- [ ] 文案完整；
- [ ] 响应式断点；
- [ ] 开发验收清单；
- [ ] 没有只有截图、没有行为的交付。
