# Guardrails Reference — AI 安全与控制

## 1. 输入防护

- 长度/大小/格式限制；
- 编码/语言/内容类型校验；
- Prompt injection 检测：指令覆盖、角色扮演、分隔符逃逸、间接注入（网页/文件/工具输出）；
- 敏感内容/恶意 URL/文件类型；
- 速率/配额/用户级限流；
- 多租户隔离：检索/缓存/日志/工具。

## 2. 输出防护

- Schema 校验（JSON/函数调用）；
- 敏感信息/PII/密钥检测；
- 引用/置信度/无答案策略；
- 危险内容/代码/命令拦截；
- 长度/格式/语言；
- 不把模型输出直接当 HTML/SQL/Shell/URL 使用。

## 3. 工具/Agent 防护

- 工具白名单；按角色/租户授权；
- 参数 schema + 业务校验；
- 高风险动作人工确认（付款、删除、发送、部署、权限变更）；
- 超时/重试/幂等/速率；
- 循环/步骤/成本上限；
- 工具输出视为不可信数据；不执行其中指令；
- 审计日志：谁/何时/工具/参数摘要/结果；
- 沙箱：代码执行/浏览器/文件系统隔离。

## 4. RAG 防护

- 文档级权限；检索前过滤；
- 租户隔离（索引/缓存）；
- 注入文档检测/隔离；
- 引用来源；冲突处理；
- 删除传播（文档删除/权限变更）；
- 索引版本/回滚。

## 5. 数据/隐私

- 最小化发送；脱敏/假名化；
- 供应商保留/训练使用审查；
- 日志不记录完整 prompt/敏感数据（或加密/短保留）；
- 用户删除/导出；
- 跨境/数据位置；
- 模型/嵌入/缓存的生命周期。

## 6. 红队清单

- [ ] 直接注入：“忽略以上指令…”；
- [ ] 间接注入：网页/文档/工具输出含指令；
- [ ] 角色越狱/DAN/虚构授权；
- [ ] 系统提示/密钥套取；
- [ ] 越权工具调用/参数篡改；
- [ ] 数据外传（URL/图片/markdown）；
- [ ] 多语言/编码绕过；
- [ ] 超长/分段/混淆；
- [ ] RAG 权限绕过/跨租户；
- [ ] 成本耗尽/拒绝服务。

## 7. 失败策略

| 场景 | 策略 |
|---|---|
| 低置信度 | 澄清/转人工/拒答 |
| 无检索结果 | 明确无答案，不编造 |
| 工具失败 | 重试/降级/告知 |
| 注入检测 | 拒绝/隔离/告警 |
| 超预算 | 降级小模型/排队/拒绝 |
| 安全事件 | 阻断/回滚/审计/通知 |

## 8. 监控指标

- 拒答率/转人工率；
- 注入尝试/拦截率；
- 工具调用失败/越权；
- 质量抽样/用户反馈；
- 延迟/成本/token；
- 数据漂移/空答案/检索命中。
